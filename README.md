# Nirmal-1

An original, modular AGI research system decoupling cognitive orchestration from an efficient hybrid state-space / attention neural backbone.

This public repository is an active research exploration. It is not claimed to be artificial general intelligence (AGI), and it does not guarantee emergent reasoning. Components are designed to be modular, reproducible, and empirically testable.

See `AGI_SPEC.md` for the architecture specification and the `src/`, `tests/`, `evals/`, `training/`, `scripts/`, `docs/`, and `experiments/` directories for implementation and research material.
